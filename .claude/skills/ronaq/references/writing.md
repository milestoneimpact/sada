# رونق · الكتابة في الواجهة

## القواعد
1. **الزرّ فعلٌ يقول ما يحدث**: «اختبر واحفظ»، «جدول 3 منشورات» — لا «موافق» ولا «إرسال».
2. **الرسالة تقول ما وقع، بالماضي المبنيّ للمجهول**: «حُفظ مفتاح Gemini» — لا «تمّت العمليّة بنجاح!».
3. **الخطأ = السبب + العلاج**، بلا اعتذار ولا «حدث خطأ ما»: «رفض Anthropic المفتاح (401). أنشئ مفتاحًا جديدًا ثمّ استبدله.»
4. **العطل يقول عاقبته**: «إن بقي: تقف الكتابة، و3 منشورات مجدولة غدًا لن تُكتب.»
5. **اسمِ الأشياء بما يعرفه المستخدم**: «المفاتيح» لا «بيانات الاعتماد»، «المزوّد» لا «الـ endpoint».
6. **جملةٌ قصيرة، وفعلٌ في أوّلها.** لا تعجّب، ولا «من فضلك» في كلّ سطر.
7. **العربيّ والإنجليزيّ لا يتداخلان**: المصطلح الإنجليزيّ معزول، والأرقام قاعدةٌ واحدة في المنصّة.
8. **«مُريح» يحذف لا يبسّط الخطأ**: يُخفي الأرقام التقنيّة، ولا يُخفي السبب ولا العلاج.

## الأطوال
| العنصر | الحدّ |
|---|---|
| زرّ | 1–3 كلمات |
| عنوان قسم | 2–5 كلمات |
| وصف قسم | سطرٌ أو سطران |
| رسالة | سطرٌ واحد |
| تلميح | جملتان، الثانية فعل |

| استعمل | لا تستعمل |
|---|---|
| مفتاح | رمز، توكن، credential |
| مزوّد | خدمة، API، endpoint |
| نموذج | محرّك، موديل |
| مهمّة | وظيفة، task |
| مصدر | ملفّ (حين يُقصد ما يُحلَّل) |
| منشور | بوست، تغريدة |
| خطّة | جدول المحتوى |
| اختبر | تحقّق، ping |
| استبدل | حدّث المفتاح |
| تراجع | إلغاء (للفعل الأخير) |
