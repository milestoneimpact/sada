## 0. التعليمات للوكيل قبل البدء

1. اقرأ هذا الملف كاملًا، ثم استكشف المستودع وحدّد: مكان متغيرات CSS (`:root`)، ومكوّن الهيكل العام (header + nav)، ومكوّنات الأزرار والبطاقات والوسوم.
2. **لا تغيّر أي اسم صفحة أو عنوان أو مصطلح قائم** (الرئيسيّة، الخطّة، المنشورات، النتائج، المكتبة، حزمة المحتوى، الحسابات، ما عليك، الإعدادات، رحلة المنشور، ما ينتظرك …). أي اسم بديل يُقترح في تقرير منفصل ولا يُطبَّق.
3. **لا تغيّر منطق البيانات أو الـ API.** العمل في طبقة العرض: CSS والقوالب والمكوّنات وترتيب العناصر.
4. نفّذ على فرع جديد `redesign/v1`، بمراحل (القسم 9)، و commit لكل مرحلة، و Pull Request واحد في النهاية مع لقطات قبل/بعد.
5. اللغة RTL بالكامل. استخدم الخصائص المنطقية (`margin-inline-start`, `padding-inline`, `inset-inline-end`) بدل left/right.
6. الأرقام بالخط اللاتيني (0-9) في كل الواجهة.

## 1. الهدف

تحويل «صدى» إلى لوحة تحكم فاخرة وهادئة وواضحة، يعرف فيها المستخدم خلال 3 ثوانٍ: **ما الذي يحتاج قراره الآن، وما حال النشر هذا الأسبوع.**

### مبادئ التصميم

| المبدأ | التطبيق |
|---|---|
| إجراء واحد واضح لكل حالة | كل تنبيه يحمل زرًا واحدًا، ولا يتكرر التنبيه في أكثر من مكان |
| التسلسل البصري | عنصر واحد بارز في كل شاشة، والباقي يتدرج في الوزن |
| الهدوء | مساحات بيضاء أوسع، وظلال أقل، وحدود دقيقة |
| الثقة | لا بيانات قديمة ظاهرة بلا تنبيه، ولا أرقام صفرية بلا سياق |
| الاتساق | رأس صفحة واحد، ونظام أزرار واحد، ووسوم حالة بقاعدة واحدة |

## 2. المشكلات الحالية (مرجع)

### 2.1 الهيكل
- **رأسان مختلفان للصفحة:**
  - النوع A (الرئيسيّة، المنشورات، المكتبة، الحسابات، الإعدادات): شعار + شارة «يعمل» + إشعارات + حساب.
  - النوع B (الخطّة، النتائج، حزمة المحتوى، ما عليك): كلمة «صدى» + رابط رجوع `← المنشورات` / `← اللوحة` + أيقونات أصغر.
- **شريط تبويب سفلي على الحاسوب** (نمط جوال)، وأقسام مهمة مخفية تحت «المزيد».
- روابط التنقّل مكررة في DOM، و«بحث وأوامر» بلا مدخل ظاهر.

### 2.2 الرئيسيّة
- تنبيه YouTube يظهر 3 مرات: شريط أحمر أعلى الصفحة + زر «جدّد إذن YouTube» + بند في «ما ينتظرك».
- 4 بطاقات أرقام كلها 0 تحتل أفضل مساحة.
- «رحلة المنشور» غير مفهومة: أشرطة بأطوال متفاوتة، و«النتائج» = 0 مع وسم «تامّة».
- «خطّةُ أسبوع» تعرض أسبوع 4-10 أكتوبر بينما اليوم 16 نوفمبر.
- «يُنشر اليوم» صندوق كامل لعبارة فارغة، و«هذا الأسبوع» 7 خانات فارغة.
- «الكلفة وما وقع» بطاقة بلا محتوى أو رابط واضح.

### 2.3 المكوّنات
- 3 أنماط أزرار بلا قاعدة (بيضاوي `radius: 999px`، مستطيل بإطار، ممتلئ).
- إجراءات حرجة كروابط نصية («جدّد»، «افتح الحسابات»).
- وسوم الحالة («تامّة»، «تنتظرك») صغيرة ومتقاربة.
- **المكتبة:** حقل رفع ملفات أصلي بالإنجليزية (`Choose Files / No file chosen`) بلا تنسيق، وزر عائم `+` يتداخل مع المحتوى.
- **المنشورات:** شريط فلاتر مزدحم بـ 8 أرقام، وزر `?` عائم، ومربع صورة رمادي فارغ في البطاقة.
- **الخطّة:** عناوين المنشورات مقطوعة، والخانات صغيرة.
- **حزمة المحتوى:** أزرار مكدسة عموديًا بعروض مختلفة.
- **ما عليك:** فقرات نصية كثيفة بلا تقسيم.
- **النتائج:** «لم يُقَس» بخط ذهبي كبير، فالحالة الفارغة أثقل من البيانات.

## 3. نظام التصميم (Design Tokens)

المتغيرات الحالية موجودة ومنظمة جيدًا. **حدّثها في مكانها ولا تنشئ نظامًا موازيًا.**

### 3.1 الألوان — الوضع الفاتح

```css
:root {
  /* الأرضيات */
  --bg: #f6f5f1;          /* كان #f4f7f6 — أدفأ قليلًا */
  --surface: #ffffff;
  --surface-2: #f1f0eb;
  --surface-3: #e8e6df;
  --line: #e4e1d8;
  --line-soft: #efede7;

  /* الحبر */
  --ink: #0f1d1e;
  --ink-2: #3a4b4a;
  --ink-3: #6b7a79;       /* أفتح لنصوص الوصف الثانوية */

  /* الهوية */
  --brand: #0e6b64;
  --brand-hover: #0b5c56;
  --brand-press: #084b46;
  --accent: #0b2f31;      /* للشريط الجانبي */
  --au: #a07a2c;          /* ذهبي — للتمييز فقط (الصفحة النشطة، رقم بارز) */
  --au-wash: #f6efe0;

  /* الحالات الدلالية */
  --ok: #0f7a52;    --ok-wash: #e3f4ec;
  --warn: #b45309;  --warn-wash: #fdf1dc;
  --bad: #b42318;   --bad-wash: #fdeceb;
  --idle: #6b7a79;  --idle-wash: #eeeeea;
}
```

### 3.2 الوضع الداكن
الإعدادات تحتوي خيار «داكن». تأكّد أن كل متغير أعلاه له مقابل داكن:

```css
[data-theme="dark"] {
  --bg: #0c1414; --surface: #121c1c; --surface-2: #182424; --surface-3: #1f2d2d;
  --line: #263535; --line-soft: #1c2929;
  --ink: #e8efee; --ink-2: #b5c3c1; --ink-3: #82918f;
  --brand: #2fa197; --brand-hover: #3bb3a8; --accent: #081010;
  --au: #d1a650; --au-wash: #2a2416;
  --ok-wash: #11302a; --warn-wash: #33260f; --bad-wash: #3a1614; --idle-wash: #1f2a2a;
}
```

### 3.3 الطباعة
السلّم موجود (`--t-display` … `--t-caption`). المطلوب **تطبيقه فعليًا**:

| الاستخدام | المتغير | الحجم | الوزن |
|---|---|---|---|
| عنوان الصفحة (h1) | `--t-h1` | 28px | 700 |
| عنوان القسم/البطاقة (h2) | `--t-h3` | 18px | 600 |
| رقم مؤشر كبير | `--t-display` | 40px | 600، خط `Plex Sans` |
| نص أساسي | `--t-ui` | 15px | 400 |
| وصف ثانوي | `--t-small` | 14px | 400، لون `--ink-3` |
| وسم/تسمية | `--t-caption` | 13px | 500 |

- حاليًا `h1` في الرأس بحجم 15px. عنوان الصفحة يجب أن يكون `h1` الوحيد في الصفحة.
- الأرقام: `font-variant-numeric: tabular-nums;`.

### 3.4 المسافات والزوايا والظلال

```css
:root {
  --r-sm: 8px;    /* وسوم، حقول صغيرة */
  --r-md: 10px;   /* أزرار، حقول */
  --r-lg: 16px;   /* بطاقات */
  --r-xl: 20px;   /* نوافذ منبثقة */

  --pad-card: 24px;     /* 20px على الجوال */
  --gap-card: 16px;
  --gap-section: 32px;

  --sh-1: 0 1px 0 rgba(15,29,30,.04);                 /* البطاقة: حد + ظل شبه معدوم */
  --sh-2: 0 4px 16px -4px rgba(15,29,30,.10);         /* عند المرور */
  --sh-3: 0 24px 48px -12px rgba(15,29,30,.22);       /* نوافذ */
}
```

- البطاقة: `background: var(--surface); border: 1px solid var(--line); border-radius: var(--r-lg); box-shadow: var(--sh-1);`
- **ألغِ** `radius: 999px` من الأزرار. يبقى البيضاوي للوسوم والشارات فقط.

### 3.5 الحركة

```css
:root {
  --dur-1: 120ms; --dur-2: 200ms; --dur-3: 320ms;
  --ease: cubic-bezier(.2,.8,.2,1);
}
@media (prefers-reduced-motion: reduce) { * { transition: none !important; animation: none !important; } }
```

احترم أيضًا إعداد «الحركة: مخفّفة» الموجود في الإعدادات.

### 3.6 الأيقونات
مجموعة واحدة فقط (يُفضَّل Lucide)، بسماكة 1.75px، وأحجام 16 / 20 / 24. استبدل أي أيقونة من مصدر آخر.

## 4. الهيكل العام (App Shell)

### 4.1 على الحاسوب (≥ 1024px)

```
┌──────────────────────────────────────────────┬────────────┐
│  رأس الصفحة (64px)                            │            │
│  [عنوان الصفحة]      [بحث ⌘K] [حالة] [🔔] [👤] │  الشريط    │
├──────────────────────────────────────────────┤  الجانبي   │
│                                              │  (248px)   │
│  المحتوى (max-width: 1200px، هوامش 32px)       │            │
│                                              │            │
└──────────────────────────────────────────────┴────────────┘
```

**الشريط الجانبي (يمين، ثابت):**
- أعلاه: الشعار + «صدى» + اسم المساحة («تجريبي»).
- المجموعة الأولى: الرئيسيّة، الخطّة، المنشورات، النتائج.
- المجموعة الثانية: المكتبة، حزمة المحتوى، الحسابات، ما عليك.
- أسفله: الإعدادات + شارة حالة النظام («يعمل»).
- العنصر النشط: خلفية `--selected`، وشريط ذهبي 3px على الحافة `inline-start`، ونص بوزن 600.
- العدّادات (مثل الحسابات `1`) شارة صغيرة على يسار العنصر.
- قابل للطي إلى 72px (أيقونات فقط) مع حفظ الحالة في `localStorage`.

**رأس الصفحة (موحّد لكل الصفحات):**
- `h1` بعنوان الصفحة.
- زر «بحث وأوامر» بشكل حقل بحث مع اختصار `⌘K` / `Ctrl K`، يفتح لوحة أوامر (command palette).
- شارة الحالة، والإشعارات، والحساب.
- **احذف** روابط الرجوع (`← المنشورات`، `← اللوحة`) ونمط الرأس B كاملًا.
- التبويبات الفرعية (مثل الخطّة / عرض للطباعة / خطّة جديدة) تظهر تحت العنوان مباشرة كتبويبات بخط سفلي.

### 4.2 الجهاز اللوحي (768–1023px)
الشريط الجانبي مطويّ (72px أيقونات) ويتوسع عند الضغط كطبقة فوق المحتوى.

### 4.3 الجوال (< 768px)
- شريط سفلي بـ 5 عناصر: الرئيسيّة، الخطّة، المنشورات، النتائج، المزيد.
- «المزيد» يفتح ورقة سفلية (bottom sheet) بباقي الأقسام.
- زر «منشور جديد» عائم في الزاوية فوق الشريط السفلي، ولا يغطي المحتوى (أضف `padding-bottom` كافيًا للصفحة).
- رأس مختصر: العنوان + الإشعارات + الحساب.

### 4.4 التنبيه العام (System Banner)
- مكوّن واحد فقط أعلى المحتوى، يظهر عند وجود عطل يوقف النشر.
- الشكل: خلفية `--bad-wash`، وأيقونة، ونص قصير، و**زر** إجراء واحد (`جدّد إذن YouTube`)، وزر إغلاق مؤقت.
- عند ظهوره: احذف الزر المكرر من رأس الرئيسيّة، واحذف البند المكرر من «ما ينتظرك».

## 5. المكوّنات

### 5.1 الأزرار

| النوع | الاستخدام | الشكل |
|---|---|---|
| Primary | إجراء واحد رئيسي في الشاشة | ممتلئ `--brand`، نص أبيض |
| Secondary | إجراءات مساندة | خلفية `--surface`، حد `--line`، نص `--ink` |
| Ghost | إجراءات داخل البطاقات والجداول | بلا خلفية، hover بـ `--surface-2` |
| Danger | حذف/إلغاء ربط | نص `--bad`، وعند التأكيد ممتلئ `--bad` |

- الأحجام: `sm` 32px / `md` 40px / `lg` 48px. الزوايا `--r-md`.
- أيقونة اختيارية قبل النص، بمسافة 8px.
- الحالات: `hover`، `active`، `focus-visible` (حلقة 2px `--brand` بمسافة 2px)، `disabled` (شفافية 0.5)، `loading` (مؤشر دوران يحل محل الأيقونة).
- **قاعدة:** زر Primary واحد كحد أقصى في كل بطاقة.
- حوّل كل الروابط النصية التي تنفذ إجراءات («جدّد»، «افتح الحسابات»، «افصل المستودع») إلى أزرار.

### 5.2 وسوم الحالة (Status Badge)

| الحالة | اللون | الأيقونة | أمثلة |
|---|---|---|---|
| تامّة / متصلة / نُشر | `--ok` على `--ok-wash` | ✓ دائرة | تامّة، متّصلة |
| تنتظرك / بلا موعد | `--warn` على `--warn-wash` | ساعة | تنتظرك، معتمدة بلا موعد |
| فشلت / تحتاج إعادة ربط | `--bad` على `--bad-wash` | تحذير | تعثّرت المزامنة |
| مسوّدة / لم يبدأ | `--idle` على `--idle-wash` | دائرة فارغة | مسوّدة · الإصدار 1 |

الحجم: ارتفاع 24px، `padding-inline: 8px`، `border-radius: 999px`، خط 13px وزن 500.

### 5.3 البطاقة (Card)
- رأس: عنوان (h2) + وصف ثانوي اختياري + إجراء واحد على اليسار (Ghost أو رابط «عرض الكل»).
- جسم بـ `--pad-card`.
- تذييل اختياري بحد علوي `--line-soft` للأزرار.
- البطاقات القابلة للنقر: `hover` يرفعها بـ `--sh-2` و `translateY(-1px)`.

### 5.4 مؤشر رقمي (Stat)
- تسمية صغيرة (13px، `--ink-3`) + رقم كبير (`--t-display`) + سطر سياق (تغيّر عن الأسبوع الماضي أو جملة توضيح).
- عند القيمة 0: الرقم بلون `--ink-3` وسطر السياق يوجّه («لا منشورات مجدولة — جدول مسوّدة»).

### 5.5 الحالة الفارغة (Empty State)
- أيقونة خطّية 32px بلون `--ink-3` + جملة واحدة + زر Secondary يقود للإجراء.
- ارتفاع مضغوط (لا تتجاوز 160px). **ممنوع** استخدام «—» أو صناديق فارغة متكررة.

### 5.6 الحقول
- ارتفاع 40px، `--r-md`، حد `--line`، `focus` بحلقة `--brand`.
- **رفع الملفات:** أخفِ `input[type=file]` الأصلي، واستبدله بمنطقة سحب وإفلات (dropzone) بنص عربي: «اسحب الملفات هنا أو اختر من جهازك»، مع قائمة الصيغ المقبولة والحد (10MB).

### 5.7 التبويبات والفلاتر
- تبويبات: نص + خط سفلي 2px `--brand` للنشط.
- الفلاتر في صفحة المنشورات: **شريط مقسّم (segmented control)** واحد لحالة المنشور مع العدد بجانب كل عنصر، وقوائم منسدلة منفصلة للمنصة والترتيب. على الجوال يصبح الشريط قابلًا للتمرير أفقيًا.

### 5.8 الجداول والقوائم
- صف بارتفاع 56px، وحد سفلي `--line-soft`، و`hover` بـ `--surface-2`.
- الإجراءات تظهر عند المرور على الحاسوب، ودائمًا على الجوال عبر قائمة `⋯`.

### 5.9 التحميل
- Skeleton بلون `--surface-2` مع وميض خفيف لكل بطاقة أثناء جلب البيانات، بدل الشاشة الفارغة.

### 5.10 الإشعارات المؤقتة (Toast)
- أسفل الشاشة في الوسط، تختفي بعد 4 ثوانٍ، مع زر «تراجع» للإجراءات القابلة للتراجع.

## 6. الصفحات

### 6.1 الرئيسيّة (`/panel#overview`)

**الترتيب الجديد من الأعلى:**

1. **التنبيه العام** (إن وُجد) — القسم 4.4.
2. **رأس الترحيب:** «نهارك سعيد» (h1 يبقى كما هو) + سطر حالة واحد: «2 بانتظار قرارك · 0 مجدولة هذا الأسبوع» + زر Primary «منشور جديد».
3. **بطاقة «ما ينتظرك»** — تنتقل إلى القمة، بعرض كامل:
   - قائمة عناصر قابلة للتنفيذ، لكل عنصر: أيقونة حالة + جملة + زر.
   - أمثلة: «منشوران بلا موعد ← اختر موعدًا»، «مصدران ينتظران التحليل ← راجع المصادر».
   - الزران «مسح Drive الآن» و«مراجعة المصادر» يصبحان Secondary داخل البطاقة.
   - إن لم يوجد شيء: حالة فارغة إيجابية «لا شيء ينتظرك الآن».
4. **صف المؤشرات:** 4 مؤشرات (بانتظار قرارك، مجدولة، نُشرت هذا الأسبوع، فشلت هذا الأسبوع) في صف واحد داخل بطاقة واحدة، بحجم مضغوط، وفق 5.4.
5. **شبكة بعمودين (على الحاسوب):**
   - **العمود الأعرض (2/3): «هذا الأسبوع»** — يدمج «يُنشر اليوم» داخله: اليوم مُبرز بإطار `--brand`، وكل يوم يعرض المنشورات المجدولة كنقاط ملوّنة بلون المنصة (`--pf-*`) مع عددها، والنقر على اليوم يفتح قائمة منشوراته. يُحذف صندوق «يُنشر اليوم» المستقل.
   - **العمود الأضيق (1/3): «رحلة المنشور»** — تتحول إلى خط مراحل عمودي (vertical stepper): المصدر ← المسوّدة ← الصورة ← الاعتماد ← الموعد ← النشر ← النتائج. لكل مرحلة: دائرة حالة (تامّة/تنتظرك) + الاسم + الرقم + السطر الوصفي. المرحلة التي «تنتظرك» تُبرز بخلفية `--warn-wash`. **احذف الأشرطة الأفقية.**
6. **«خطّةُ أسبوع»:**
   - إذا كان أسبوع الخطة منتهيًا: يظهر وسم `--warn` «خطة منتهية» + زر Primary «أنشئ خطة الأسبوع الحالي» بدل «تابع الكتابة».
   - شريط التقدم أعرض (8px) مع النص «0 من 4 معتمدة».
7. **«الكلفة وما وقع»:** بطاقة مضغوطة تعرض رقمين (إنفاق اليوم، إنفاق 14 يومًا) + رابط «التفاصيل».
8. التذييل: «صدى · 2026-11-16 13:28 بتوقيت الرياض» بخط 13px `--ink-3`.

### 6.2 الخطّة (`/panel/plan`)
- رأس موحّد (احذف `← المنشورات`). التبويبات الفرعية (الخطّة، عرض للطباعة، خطّة جديدة) تحت العنوان.
- سطر الحالة: وسم «مسوّدة · الإصدار 1» + «كُتب 0 من 4» + زر Primary «تابع الكتابة».
- أزرار العرض (بطاقات / قائمة) تصبح segmented control، و«أفعال الخطّة» قائمة `⋯`.
- **عرض البطاقات:** شبكة 7 أعمدة على الحاسوب، وكل منشور بطاقة صغيرة: شريط علوي بلون المنصة، والوقت، والعنوان على سطرين (`-webkit-line-clamp: 2`) بدل القطع بنقاط. على الجوال: قائمة أيام عمودية.
- «شارك مع العميل» يصبح زر Secondary بأيقونة مشاركة.

### 6.3 المنشورات (`/panel#posts`)
- التبويبات (المسوّدات، اكتب، الخطّة) كما هي.
- الفلاتر وفق 5.7.
- احذف زر `?` العائم، وانقل المساعدة إلى أيقونة `ⓘ` بجانب العنوان بتلميح (tooltip).
- **بطاقة المنشور الجديدة:**
  - صورة مصغّرة 96×96 (أو 16:9 في عرض الشبكة)، وعند غيابها أيقونة المنصة على خلفية `--surface-2` بدل المربع الرمادي الفارغ.
  - المنصة (أيقونة + اسم) + وقت الإنشاء.
  - النص على 3 أسطر كحد أقصى.
  - وسم الحالة في الزاوية.
  - الإجراءات: زر Secondary «افتح» + قائمة `⋯`.
- خيار عرض: قائمة / شبكة.

### 6.4 النتائج (`/panel/report`)
- رأس موحّد (احذف `← اللوحة`).
- مؤشرات الظهور والتفاعل والإنفاق وفق 5.4.
- عند غياب القياس: الرقم «—» بلون `--ink-3` بحجم المؤشر العادي + سطر «لم يُقَس بعد» بخط 13px. **ألغِ** النص الذهبي الكبير.
- رسوم بيانية (إن وُجدت بيانات): خط زمني بسيط بلون `--brand`، بلا شبكة كثيفة.

### 6.5 المكتبة (`/panel/library`)
- بطاقة «أضف مصدرًا» بعمودين: dropzone للملفات (5.6) + حقل الروابط مع زر «اقرأ الروابط».
- احذف الزر العائم `+` على الحاسوب. على الجوال يبقى زر «منشور جديد» العائم الوحيد.
- قسم «ملفات مجلّدك» بقائمة وفق 5.8.

### 6.6 حزمة المحتوى (`/panel/package`)
- رأس موحّد (احذف `← المكتبة`).
- بطاقة «المزامنة»: وسم الحالة بارز في رأس البطاقة، ثم سطر آخر دفعة، ثم صف أزرار أفقي بعرض متساوٍ: Primary «زامن الآن»، Secondary «اختبر الرمز» و«اربط التحديث الفوري»، و«افصل المستودع» Danger Ghost منفصلًا في التذييل.

### 6.7 الحسابات (`/panel/accounts`)
- المؤشرات الثلاثة (متّصلة، تحتاج إعادة ربط، تحتاج إعدادًا) وفق 5.4، و«تحتاج إعادة ربط» بإطار `--bad` عند وجود قيمة.
- بطاقة كل حساب: شعار المنصة بلونها + الاسم + الصفحة المرتبطة + وسم الحالة + زر إجراء (إعادة الربط Primary عند الحاجة).
- الحسابات التي تحتاج تدخلًا تظهر أولًا.

### 6.8 ما عليك (`/panel/tasks`)
- رأس موحّد (احذف `← اللوحة`).
- الفقرة التعريفية في بطاقة قابلة للطي («كيف تعمل هذه القائمة»).
- كل مهمة: بطاقة قابلة للتوسيع (accordion)، رأسها: المعرّف (M-16) + العنوان + وسوم + سهم. الجسم: النص مقسّم بفقرات قصيرة وعناوين فرعية.

### 6.9 الإعدادات (`/panel/settings`)
- تخطيط بعمودين على الحاسوب: قائمة الأقسام (المظهر، الإنفاق والحدود، الأمان، متقدّم) على اليمين بدل التبويبات، والمحتوى على اليسار.
- كل إعداد: صف بتسمية + وصف + عنصر تحكّم (segmented control أو toggle) محاذى لليسار.

## 7. الوصول (Accessibility)
- تباين النص ≥ 4.5:1 (يُفحص للوضعين).
- كل عنصر تفاعلي قابل للوصول بلوحة المفاتيح مع `focus-visible` واضح.
- مساحة لمس ≥ 44×44px على الجوال.
- `aria-label` لكل زر أيقونة فقط، و`aria-current="page"` للصفحة النشطة.
- الحالة لا تُنقل باللون وحده (أيقونة + نص دائمًا).
- عنوان `h1` واحد لكل صفحة.
