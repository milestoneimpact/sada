# ملفّ التسليم: صدى

> آخر تحديث: 2026-10-14 · `main` عند D-203 (#141) · staging على sada2.basserh.com، والإنتاج sada.basserh.com لم يُطلَق (M-22).

## ١ · ما هو صدى

مديرُ محتوى عربيّ لمالكٍ واحد على Cloudflare (Worker بـ Hono، وD1، وKV، وR2، وQueues). يقرأ مصادر المالك، فيكتب مسوّداتٍ لكلّ منصّة، ويصنع صورها، وينتظر اعتماده، ثمّ ينشر في الموعد على LinkedIn وX وInstagram وTikTok وYouTube، ويقيس ما ينشره.

## ٣ · قبل كلّ دفعة

```
npm run ci                                             # الأنواع والبوّابات والاختبارات (2601)
flock /tmp/sada-audit.lock npm run audit               # التصميم والسلّم والجوّال والطباعة وCSP والروابط
flock /tmp/sada-audit.lock bash -c 'npm run render && npm run text'
npm run journeys                                       # الرحلات المقيسة على نسخةٍ حيّة: 26 من 26
```

ولا تُضعَف بوّابة لتمرّ. والطلبُ يُفتح مسوّدةً، ثمّ يُعلَّم جاهزًا مرّةً واحدة، ويُدمج squash، ونشرُ `main` إلى staging آليّ (`deploy.yml`).

## ٤ · الخطوط التي لا تُتجاوز

- لا رمزَ ولا سرَّ في محادثةٍ ولا سجلٍّ ولا `wrangler.toml`. والرموزُ مشفّرةٌ في D1 بـ AES-GCM، والمفتاحُ في أسرار Worker (D-005).
- لا طلبَ نشرٍ بلا `idempotency_key` (D-004).
- لا إنفاقَ آليّ على الإعلانات (D-006).
- كلُّ نداءٍ مدفوع يُسجَّل في `cost_ledger` قبل أن يُعدّ ناجحًا (D-008).
- الترحيلُ قبل الدالّة.
- لا خلطَ بين sada.basserh.com (الإنتاج) وsada2.basserh.com (staging).

## ٧ · ما على المالك الآن

### رصيدُ AI Gateway لتحريك الصورة (الأحدث)

ظهر للمالك: «تعذّر تحريك الصورة: لا رصيدَ في AI Gateway لنماذج الطرف الثالث (402 — 2021: Insufficient balance)». الشيفرةُ تعمل؛ النموذجُ `alibaba/hh1-i2v` يُحاسَب بالفوترة الموحّدة لـ Cloudflare، والرصيدُ صفر.

| # | العنصر | التفصيل |
|---|---|---|
| ١ | ما هو | إضافةُ رصيدٍ إلى AI Gateway في حساب Cloudflare الذي يعمل عليه صدى |
| ٢ | لماذا الآن | زرُّ «حرّكها فيديو» يمرّ بالبوّابة، وكلُّ ضغطةٍ تُردّ 402 حتّى يوجد رصيد |
| ٣ | الخطوات | 1. ادخل dash.cloudflare.com بحساب صدى. 2. من القائمة: AI ← AI Gateway. 3. افتح البوّابة `default`. 4. ابحث عن «Credits» أو «Unified Billing» واضغط «Add credits». 5. أضف مبلغًا صغيرًا للتجربة (5 دولارات مثلًا). |
| ٤ | ما يعني النجاح | في اللوحة يظهر رصيدٌ أكبر من صفر، وضغطةُ «حرّكها فيديو» على صورةٍ تعطي مقطعًا لا رسالةَ 402، ويظهر نداؤه في سجلّ الكلفة |
| ٥ | ماذا لو فشل | إن لم تجد «Add credits» فأرسل لقطةً لصفحة البوّابة. وإن بقي 402 بعد الإضافة فأرسل نصَّ الرسالة الجديدة كما هو |
| ٦ | ما يقع إن تُرك | لا تحريكَ للصور إلى فيديو، وكلُّ ما سواه يعمل: الكتابةُ والصورُ والنشر. **تأجيلٌ لا خطر**، ولا يُصرف شيءٌ دونك |

والبديلُ «BYOK»: مفتاحُ مزوّد النموذج نفسه في البوّابة بدل الرصيد، وهو أعقد ولا داعي له الآن.
