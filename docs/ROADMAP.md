## ٦ · كيف تُقرأ هذه الخارطة وتُحدَّث

- **البندُ يُغلق بطلب دمجٍ يحمل رقمَ قراره** (D-NNN)، ويُحذف من §٣ في الطلب نفسِه، ويُضاف سطرُه إلى `STATUS.md`.
- **لا يُقال «تمّ» عن مهمّة مالكٍ قبل أن يقول المالك** (CLAUDE.md)، و`/panel/tasks` يقيس ما يُقاس.
- **الحجم**: صغيرٌ طلبٌ في جلسة، ومتوسّطٌ طلبٌ بلقطاتٍ قبل وبعد، وكبيرٌ يُقسَّم طلباتٍ يُردّ كلٌّ منها وحده (DESIGN-PLAN §11).
- **قبل كلّ دفعة**: `npm run ci`، و`npm run audit` (وآخرُه حارسُ النصّ `npm run copy`)، و`npm run journeys`.
