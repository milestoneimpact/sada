# صدى — Sada

**مدير محتوى ذكي، لا أداة جدولة.**

صدى يقرأ مصادرك في Google Drive، ويقرّر ما يستحقّ الظهور، ويخطّط الشهر، ويكتب،
ويصمّم، ثمّ ينشر على LinkedIn وX، ويقيس، ويقترح أين يُنفَق مبلغٌ صغير لزيادة
الوصول. النشر نفسه أرخص مكوّن في السلسلة وأسهله؛ القيمة في طبقة الذكاء
وطبقة الحوكمة: من يوافق، ومتى، وبأيّ سقف.

> الاسم: «صدى» — ما تكتبه يعود إليك صدًى من الوصول والأثر.
> النطاقان المقترحان: `sada.basserh.com` للإنتاج، `sada2.basserh.com` لـ staging.

## الطبقات الثلاث

| الطبقة | ما تفعله | المكوّنات |
|---|---|---|
| **الفهم** | تقرأ Drive وتُخرج خطّة شهرية بصيغة JSON ثابتة | Drive API · Claude · D1 |
| **الإنتاج** | تكتب النصّ، تولّد الصور، تخزّن، ثمّ تنتظر اعتمادًا بشريًّا | Claude · Gemini · R2 · لوحة الاعتماد |
| **التوزيع** | تجدول، تنشر بمفتاح `idempotency`، تسجّل التكلفة، تقيس | Cron · Queues · Publisher Worker · LinkedIn API · X API |
